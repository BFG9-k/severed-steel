# Internal trainer for [Severed Steel](https://store.steampowered.com/app/1227690/Severed_Steel/)

## Features

**NPC**
- ESP for NPCs
- Harmless NPCs

**Movement**
- Teleport to NPCs
- Speedhack
- Jumphack
- Fast Wallrun

**Misc**
- Infinite Slowmo
- Score Hack
